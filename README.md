# 💰 每日开销

记录每一笔购买，看清物品的真实使用成本。

---

## 这是什么

**每日开销** 帮你记录购买的物品（手机、电脑、衣物……），自动计算**已用天数**和**日均成本**（价格 ÷ 天数）。用的越久，日均成本越低——用数据告诉你哪笔钱花得值。

## 功能

- **物品管理** — 添加 / 编辑 / 删除物品，记录名称、价格、购买日期、分类、备注
- **自动计算** — 已用天数 + 日均成本，每天自动更新
- **分类筛选** — 预设 7 个分类（📱电子设备 👔衣物 🏠家居 🍔食品 🚌交通 🎮娱乐 📦其他），支持自定义
- **双展示模式** — 使用时间可切换「1年3月15天」或「400天」两种显示方式
- **统计概览** — 总消费、物品数量、平均日均成本一目了然
- **纯本地存储** — 数据存在浏览器中，无需网络，隐私安全

## 计算逻辑

```
已用天数 = 今天 - 购买日期
日均成本 = 价格 ÷ 已用天数
（当天购买时，日均成本 = 价格）
```

## 数据存储

数据存在浏览器 `localStorage` 中，Key 为 `daily-expense-data`。清除浏览器数据会导致数据丢失，后续计划支持导出备份功能。
